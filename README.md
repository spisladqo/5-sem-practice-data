## Методология

Эксперименты сравнивали время работы следующих алгоритмов:

- multsrc — базовый неоптимизированный алгоритм;
- multsrc_adv — усовершенствованная версия без оптимизаций;
- multsrc_adv -e — у.в. с оптимизацией тривиальных операций (empty);
- multsrc_adv -f — у.в. с оптимизацией благодаря хранению 2 форматов матриц (format);
- multsrc_adv -l — у.в. с оптимизацией благодаря ленивому сложению (lazy);
- multsrc_adv -b — у.в. с оптимизацией индексированных грамматик (block);
- multsrc_adv -w — у.в. с оптимизацией за счёт качественных грамматик (rewritten);
- multsrc_adv -eflbw — у.в. со всеми вышеперечисленными оптимизациями.

(Помимо возможности использовать оптимизации, усовершенствованная версия отличается представлением матриц смежности входного графа).

1. Для каждого графа в качестве начальных вершин были выбраны случайные вершины, из каждой из которых достижима хотя бы одна другая вершина. Были определены две категории: доли 1% и 5% от общего числа его вершин.
2. Было сгенерировано по 4 выборки для каждого графа и доли начальных вершин.
3. Для каждого набора (граф, выборка начальных вершин) были запущены все алгоритмы со сбором времени работы.
Количество повторений было равно от 15 до 20.
4. Для каждого набора (граф, выборка начальных вершин, процент) были получены выборки из времени работы каждого алгорима.
5. Для каждой такой выборки было взято среднее. Затем, для каждого графа и доли вершин было взято среднее от средних значений 4 сгенерированных выборок.
6. После получения результатов, их корректность была сравнена с результатами https://github.com/FormalLanguageConstrainedPathQuerying/CFPQ_PyAlgo (дата доступа: 02.09.26) по принципу пересечения множества ответов алгоритма для всех вершин с множеством начальных вершин из каждой выборки.
