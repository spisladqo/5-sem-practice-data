# Эксперименты с оптимизированным алгоритмом

В этом репозитории собраны результаты экспериментов по оптимизированной версии алгоритма достижимости для нескольких источников (ниже), а также обоснование, почему инкрементальная оптимизация неприменима к этому алгоритму (![incremental_math](<incremental_math.pdf>)).

## Окружение

- CPU: Intel(R) Core(TM) i7-10750H CPU
- RAM: 8GB DDR4
- OS: Fedora 41
- LAGraph: 1.2.1
- GraphBLAS: suitesparse-graphblas 10.1.0
- GCC: 14.3.1

## Тестовые данные

Тестовых графы и грамматики были взяты из набора данных CFPQ_Data: https://github.com/FormalLanguageConstrainedPathQuerying/CFPQ_Data (дата обращения: 14.10.26).

В качестве начальных вершин были взяты случайные вершины из множества всех вершин графа (см. раздел [Методология](#методология)).

Ссылка на архив с использованными графами, грамматиками и начальными вершинами: https://drive.google.com/file/d/1097c0lNpBJXD7i_uBhlcOlLEKzZaRdGm/view?usp=sharing (дата обращения: 14.10.26).

Эксперименты проведены с помощью инструмента CFG_bench, разработанного Ильхомом Комбаевым: https://github.com/homka122/CFG_bench (дата обращения: 14.10.26).

## Методология

Эксперименты сравнивали время работы следующих алгоритмов:

- multsrc — алгоритм из LAGraph;
- multsrc_adv — разработанный алгоритм, способный использовать оптимизации, но без их применения (для сравнения с базовой версией);
- multsrc_adv -e — с оптимизацией тривиальных операций (empty);
- multsrc_adv -f — с оптимизацией благодаря хранению 2 форматов матриц (format);
- multsrc_adv -l — с оптимизацией благодаря ленивому сложению (lazy);
- multsrc_adv -b — с оптимизацией индексированных грамматик (block);
- multsrc_adv -r — с оптимизацией за счёт улучшенных грамматик (rewritten).
- cfpq rsm — алгоритм достижимости для нескольких источников, решающий ту же задачу, но с помощью RSM, разработанный Вячеславом Давледшиным: https://github.com/Zestria/LAGraph/tree/feat/rsm-reach (дата обращения: 15.10.26).

1. Для каждого графа в качестве начальных вершин были выбраны случайные вершины, из каждой из которых достижима хотя бы одна другая вершина. Были определены две категории: доли 1% и 5% от общего числа его вершин.
2. Из этих выбранных вершин были образованы выборки для каждого графа в размере 1% и 5% от числа их вершин.
3. Для каждой выборки были запущены все алгоритмы со сбором времени работы.
Количество повторений было равно 5 для долгих алгоритмов, и 10--15 для более быстрых.
4. Для каждого набора были получены выборки из времени работы каждого алгорима.
5. Для каждой такой выборки было взято среднее и стандартное отклонение.
6. После получения результатов, их корректность была сравнена с результатами https://github.com/FormalLanguageConstrainedPathQuerying/CFPQ_PyAlgo (дата обращения: 14.10.26) по принципу пересечения множества ответов алгоритма для всех вершин с множеством начальных вершин из каждой выборки.
