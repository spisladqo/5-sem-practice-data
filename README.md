# Эксперименты с оптимизированным алгоритмом

В этом репозитории собраны результаты экспериментов по оптимизированной версии алгоритма достижимости для нескольких источников (ниже), а также обоснование, почему инкрементальная оптимизация неприменима к этому алгоритму (![incremental_math](<incremental_math.pdf>)).

## Окружение

- CPU: Intel(R) Core(TM) i7-10750H CPU
- RAM: 8GB DDR4
- OS: Fedora 41
- LAGraph: 1.2.1
- GraphBLAS: suitesparse-graphblas 10.1.0
- GCC: 14.3.1

## Тестовые данные

Тестовых графы и грамматики были взяты из набора данных CFPQ_Data: https://github.com/FormalLanguageConstrainedPathQuerying/CFPQ_Data (дата доступа: 02.09.26).

В качестве начальных вершин были взяты случайные вершины из множества всех вершин графа (см. раздел [Методология](#методология)).

Ссылка на архив с использованными графами, грамматиками и начальными вершинами: https://drive.google.com/file/d/1097c0lNpBJXD7i_uBhlcOlLEKzZaRdGm/view?usp=sharing (дата доступа: 02.09.26).


## Методология

Эксперименты сравнивали время работы следующих алгоритмов:

- multsrc_adv — разработанный алгоритм без оптимизаций;
- multsrc_adv -e — с оптимизацией тривиальных операций (empty);
- multsrc_adv -f — с оптимизацией благодаря хранению 2 форматов матриц (format);
- multsrc_adv -l — с оптимизацией благодаря ленивому сложению (lazy);
- multsrc_adv -b — с оптимизацией индексированных грамматик (block);
- multsrc_adv -r — с оптимизацией за счёт улучшенных грамматик (rewritten).

1. Для каждого графа в качестве начальных вершин были выбраны случайные вершины, из каждой из которых достижима хотя бы одна другая вершина. Были определены две категории: доли 1% и 5% от общего числа его вершин.
2. Было сгенерировано по 4 выборки для каждого графа и доли начальных вершин.
3. Для каждого набора (граф, выборка начальных вершин) были запущены все алгоритмы со сбором времени работы.
Количество повторений было равно от 15 до 20.
4. Для каждого набора (граф, выборка начальных вершин, процент) были получены выборки из времени работы каждого алгорима.
5. Для каждой такой выборки было взято среднее. Затем, для каждого графа и доли вершин было взято среднее от средних значений 4 сгенерированных выборок.
6. После получения результатов, их корректность была сравнена с результатами https://github.com/FormalLanguageConstrainedPathQuerying/CFPQ_PyAlgo (дата доступа: 06.10.26) по принципу пересечения множества ответов алгоритма для всех вершин с множеством начальных вершин из каждой выборки.
